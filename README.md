# DFAUT26-4270 Term Assessment Register Policy

Authoritative scope and conventions for the Autumn 2026 Data Fluency term
assessment register.

## Scope

The register covers the six teaching courses in the Autumn 2026 delivery set.
The program office course and the faculty course-design sandbox are outside the
register.

## Inclusion rule

The register enumerates every assessment item delivered in a scoped course:
every assignment and every quiz.  Quiz subtype and publication state are
recorded properties of an item, not inclusion criteria.  The learning platform
also materialises a placeholder assignment record for each graded quiz; those
are platform artefacts of the quiz and are not separate assessment items.

## Graded definition

An assessment item is graded when it is a graded assignment, or when it is a
quiz whose type is `assignment` or `graded_survey`.  `practice_quiz` and
`survey` quizzes are ungraded.

## Coverage rule

A scoped course is COMPLIANT when it carries at least 2 graded assessment items;
otherwise it is GAP.  A GAP course requires a follow-up announcement.
